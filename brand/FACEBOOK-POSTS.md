# Facebook launch posts

Ten posts for the first two and a half weeks: image posts, text posts, a carousel, two reels, a story and a feed video. Six are in English and four in Bangla, plus one bilingual story. Artwork is in `assets/facebook/posts/`. Page setup is in [FACEBOOK-PAGE.md](FACEBOOK-PAGE.md).

Every link uses this format:

`https://www.landlordsbd.com/?utm_source=facebook&utm_medium=organic_social&utm_campaign=property_in_order&utm_content=<utm_content>`

The videos are silent. Facebook autoplays muted, so the text is burned into the frames. Upload the matching `.srt` file as captions (Facebook names caption files `filename.en_US.srt` or `filename.bn_IN.srt`; rename if asked). Add licensed music in Facebook's editor if you want it.

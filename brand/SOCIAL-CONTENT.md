## Two-week launch cadence

| Day | Publish | Purpose |
| --- | --- | --- |
| 1 | English brand post + story sequence | Introduce the promise and app link |
| 3 | Five-card carousel | Explain the workflow |
| 5 | Brand reel | Test the scattered-admin hook |
| 7 | Bangla brand post | Reach Bangla-first owners |
| 9 | Rent post | Show a specific task |
| 11 | Document post | Explain storage and encryption |
| 14 | Story sequence with a new poll | Learn which task interests visitors |

Review account insights for audience activity before choosing posting times. Compare link visits and activation quality; avoid assuming a universal best posting time. A later reel should use a real screen recording: adding one plot, finding one document, or checking recorded rent. Keep it to one task per video.
